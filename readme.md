# Titanic Data Visualization - Mini Project

## 📌 Overview
This mini project explores the Titanic dataset using **Python, Pandas, Matplotlib, and Seaborn**.  
The goal is to perform **basic data analysis and visualizations** to understand passenger demographics and survival patterns.

## 📊 Dataset
The dataset used is the **Titanic dataset** available through Seaborn.  
It contains details such as passenger class, age, gender, fare, survival status, and more.

## 🛠️ Tools & Libraries
- Python 3
- Pandas
- Seaborn
- Matplotlib

## 📈 Visualizations Included
- Histogram of passenger ages
- Survival count by gender
- Survival rate by passenger class
- Correlation heatmap
- Fare distribution by class
